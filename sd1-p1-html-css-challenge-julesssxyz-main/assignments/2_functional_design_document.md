# Function design document HTML CSS
In this file, all the functional info you need for your challenge assignment is included.

## Functional requirements
* You need the following information on your page
  * Name
  * Profile picture
  * Description (About yourself +/- 60 words)
  * Three headers with different info:
    * Computer specs (A table)
    * Hobbies (A list)
    * A random fact of yourself with a picture
* There's a button with a link to an external page.
* There's a button with a link to mail you (the owner of the page).
* There's a button with a link to another HTML page in the same project.
* Include fonts that you can get from Google Fonts (Last step)

## Non-functional requirements
* The website should be rescaling with the width of your screen.

## Requirements for getting a "Good"
Do well on the written test.
