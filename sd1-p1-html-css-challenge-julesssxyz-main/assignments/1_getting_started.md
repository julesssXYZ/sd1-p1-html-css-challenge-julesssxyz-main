# Getting started
## Download your IDE (in this case Webstorm) and GitHub Desktop
* https://www.jetbrains.com/webstorm/
* https://github.com/apps/desktop
## Make an account for both with your student e-mail
* https://education.github.com/discount_requests/application
* https://www.jetbrains.com/shop/eform/students
## Get the repository on your device
* Go to the repo:
* Clone the repo by pressing the green button: 'Code' > Open in GitHub Desktop
* Open the folder with Webstorm

## Make a HTML and a CSS file in the project_files folder
* Right-click on the project_files folder > New > html file > type "about_me" > press enter
* Right-click on the project_files folder > New > css file > type "main" > press enter
