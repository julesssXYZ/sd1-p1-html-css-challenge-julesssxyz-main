## Wordlist
* IDE = Integrated Development Environment (Program where you write code).
* HTML = HyperText Markup Language (The info the website shows).
* CSS = Cascading Style Sheet (The style that is connected to the HTML).
* Git = A way to keep your files online, so you don't lose them, and with it, you can work together with others on the same projects easily.
* Repository = A project stored with Git
* GitHub = A platform which keeps all your repositories
* Bug = An error or flaw in the software that causes it to produce an incorrect or unexpected result.
* Debugging = The process of finding and fixing bugs or errors in the software.
* Libraries = Collections of pre-written code that developers can use to add specific functionalities to their programs.
* Plugin = An additional piece of software that adds a specific feature or functionality to an existing program.
